### What We Are Building 
Complicare HealthAudit is SaaS Software. which helps health organizations to manage their compliance requirements , evidence  , audit , risk , finding and corrective actions. 

### High-Level Architecture 

**1 Frontend: React , Vite and Typescript**.
**2 Backend: Node Js , Express and Typescript. Handles api requests and business logic.**
**3 Database: PostgressSQL.** 
**4 Database Access: Prisma ORM. Define data models and support database queries and migrations.** 
**5 Authentication: JWT-based access tokens and refresh token session management.** 
**6 Testing: Jest and SWC for backend**. 

### Basic Request Flow 
User → Frontend → Backend API → Database (when needed) → Backend Response → Frontend
